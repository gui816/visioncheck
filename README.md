# VisionCheck

Protótipo inicial de uma aplicação web de rastreio visual educativo.

## Requisitos
- Node.js 22+
- npm

## Desenvolvimento
```bash
npm install
npm run dev
```

## Verificações
```bash
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

## GitHub Pages
O Vite está configurado com `base: '/visioncheck/'`, assumindo publicação em `https://gui816.github.io/visioncheck/`.
Ativa GitHub Pages com **GitHub Actions** nas definições do repositório.

## Âmbito e segurança
Este projeto é um protótipo. Não fornece diagnóstico, não mede graduação refrativa e não substitui avaliação por optometrista ou oftalmologista. Testes clínicos e estimativas refrativas exigem desenho e validação por profissionais qualificados antes de utilização real.
